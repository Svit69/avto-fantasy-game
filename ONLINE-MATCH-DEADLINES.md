# Проверка начала матча и дедлайн

- Матч МХЛ 903310: календарь исправлен на 04.11.2026 11:00 МСК (13:00 Екб).
- Дедлайн тура не может быть позже первого матча этого тура.
- Проверенное начало игры блокирует состав независимо от успешного сбора статистики.
- При сохранении состава дедлайн проверяется повторно после расчёта цен и при записи.
- Автозаполнение использует тот же календарь и проверку времени при записи.
- Сохранённое подтверждение начала не снимается при следующем статусе «ожидание».
- Более позднее объявленное время не открывает уже закрытый состав заново.
- Наблюдение привязано к ID матча, лиге, дате и домашней/гостевой командам.
- Смена ID в админке не снимает подтверждённую блокировку той же пары команд и даты.
- МХЛ: за 24 часа начинаются проверки заголовка официальной трансляции раз в 30 минут.
- В последние 10 минут до известного начала используется обычный цикл сбора.
- Если проверка заголовка обнаружила начавшийся матч, следующий сбор будет через 5 минут.
- КХЛ использует существующий mirror, с подготовкой за сутки и интервалом 30 минут до игры.
- Частота проверок не даёт гарантии мгновенного обнаружения переноса при недоступном источнике.
- При изменении времени администратор получает отдельное уведомление.

Наблюдения хранятся в storage/runtime/online-match-schedules.json
(или RUNTIME_STATE_DIRECTORY). Этот каталог должен быть общим у приложения и воркеров.
Файл необходимо сохранять при переносе VPS. Запись атомарная и согласована с сохранением составов.
Повреждение файла не замалчивается, чтобы не открыть редактирование ошибочно.

## Неоднозначная смена вратаря МХЛ

Если в трансляции отмечены два вратаря без персональной замены, сейвы не распределяются наугад.
Для завершённой игры запрашивается официальный PDF, проверяются команды, дата, счёт и вратари.
Его вратарские показатели дополняют онлайн-статистику; ручной протокол сохраняет приоритет.
Если PDF недоступен или не прошёл проверку, прежние данные остаются нетронутыми.
Администратор получает понятное сообщение с просьбой загрузить протокол.
Для 903310 официальный PDF при проверке отвечал HTTP 403; численные показатели не угадывались.

## Проверка Сохранённых Составов

`node server/roster-deadline-audit.js Ноябрь`

Команда не меняет составы. Она показывает последние сохранения после исправленного дедлайна.
Это список для проверки, а не доказательство нарушения пользователем.
История предыдущих версий не хранится в одной текущей записи; автоматического отката нет.
Не удаляйте заявки без отдельного решения по уже начавшемуся туру.
