# Подтверждение названий ВХЛ

- Известные варианты названий и префикс ХК сопоставляются автоматически, как раньше.
- При неизвестном названии соперника импорт блокируется до решения администратора.
- Если дата, ID страницы и сторона Горняка совпали, бот предлагает подтверждение.
- Сходство написания — подсказка, а не вероятность и не автоматическое разрешение.
- Другая дата, переставленные команды и неверная сторона Горняка не подтверждаются.
- Кнопки доступны только администраторам из TELEGRAM_ADMIN_IDS в личном чате.
- Подтверждение действует только для конкретного матча, ID и показанных названий.
- Это не глобальный псевдоним команды: следующий неизвестный вариант требует проверки.
- При нажатии повторно проверяется календарь; при сборе повторно проверяется страница.
- Если данные страницы изменились, старое разрешение не позволяет обойти проверку.
- Первое решение окончательное; повторное нажатие не меняет его.
- При отклонении исправьте ID через раздел ВХЛ online.
- После подтверждения сбор продолжается в ближайший цикл воркера, не внутри вебхука.
- Подтверждённый матч ставится на повторный сбор даже вне обычного окна 48 часов.
- Запрос и разрешение действуют семь суток с создания; затем требуется ручная проверка.
- Очередь повторов сохраняется до успешного сбора завершённого матча или истечения срока.
- Уведомление об итоговом сборе использует существующую защиту от повторной отправки.
- Ожидание решения и отклонение учитываются в heartbeat отдельно, не как сбой воркера.
- Сетевые ошибки и жёсткие несовпадения продолжают учитываться как ошибки.
- При вводе ID через бота неизвестное название тоже вызывает запрос подтверждения.

Решения, автор и время сохраняются в storage/runtime/vhl-match-reviews.json
(или RUNTIME_STATE_DIRECTORY). Файл общий для приложения и воркера на одном VPS.
Запись атомарная, с межпроцессной блокировкой. Сохраните этот файл при переносе VPS.
JSON-хранилище используется также при основном PostgreSQL-драйвере.
Для нескольких VPS потребуется общее хранилище решений; локальные файлы не синхронизируются.
Приоритет загруженных вручную протоколов и правила начисления очков не изменены.

Проверки: npm run check (включает server/vhl-review-self-test.js).
