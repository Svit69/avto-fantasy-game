# Онлайн-сбор МХЛ

Страница: https://avto-box.vercel.app/mhl.html?id=903207#stats
Воркер вызывает POST /api/mhl?id=..., ожидает до пяти минут и читает
HTML завершённого свежего снимка. На VPS браузер не требуется.

## Развёртывание

```sh
cd /var/www/avto-fantasy-game
git pull
npm ci
npm run check
pm2 restart avto-fantasy --update-env
pm2 restart avto-khl-online-poll --update-env
pm2 start ecosystem.config.cjs --only avto-mhl-online-poll
pm2 save
```

Перезапуск КХЛ нужен для общей политики приоритета протоколов.
Не запускайте весь ecosystem: это может создать второй процесс ВХЛ.

## Поведение

- ID берётся из mhlGameId матча календаря МХЛ.
- Подготовка за 10 минут, пауза между запросами минимум 5 минут.
- Финальный сбор через 20 минут после обнаруженного завершения.
- После успешного финального сбора этот матч больше не опрашивается.
- При ошибке зеркало запрашивается снова, в пределах 48 часов от начала.
- После трёх ошибок подряд админу приходит одно предупреждение на матч.
- Админ получает подготовку, начало, один промежуточный и финальный отчёт.
- Проверяются ID, источник, дата, команды, колонки и суммы статистики.
- Учитываются ОТ, буллиты, замены вратарей и пустые ворота.
- Переведённые игроки ищутся во всём каталоге; коэффициент матча МХЛ 0,5.
- Не найденные в каталоге игроки перечисляются в финальном отчёте.
- Загруженный PDF всегда приоритетнее онлайн, включая статистику и API.

Настройки .env: MHL_ONLINE_POLL_INTERVAL_MS=300000,
MHL_ONLINE_FINAL_DELAY_MS=1200000. Состояние хранится отдельно в
storage/runtime/mhl-online-matches.json, heartbeat в mhl-heartbeat.json.
Сохраняйте runtime при обновлениях. /api/operations содержит mhlWorker.
