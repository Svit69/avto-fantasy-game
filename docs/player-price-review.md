# Помощник стоимости игроков

В админ-боте: `/admin` → «Помощник стоимости».
Расчёт ничего не записывает в цены и не меняет составы пользователей.
Кнопки «Изменить цену» открывают существующий ручной ввод стоимости.

## Данные

- Последний начавшийся регулярный тур и два предыдущих, определяемые по датам.
- Только завершённые импортированные матчи из календаря, без будущих матчей.
- Последний импорт каждого матча; старые строки игроков не восстанавливаются.
- Все фактически сыгранные матчи игрока, включая переходы между лигами.
- ФО уже содержат коэффициент лиги. Повторного умножения нет.
- Отсутствие строки игрока не равно нулю; настоящий ноль учитывается.
- Игроки, покинувшие игру, исключены.

## Методика первой версии

1. Для каждого тура считаются среднее, медиана и количество матчей.
2. Веса текущего и предыдущих туров: 0,6 / 0,3 / 0,1.
3. Вес тура умножается на `min(матчи / 5, 1)`, доступные веса нормализуются.
4. Оценка формы: взвешенные `0,7 × среднее + 0,3 × медиана`.
5. Разброс: стандартное отклонение / `max(abs(среднее), 10)` по всем матчам.
6. Стабильность: `1 / (1 + разброс)`.
7. Сравнение только с другими игроками текущей команды и той же позиции.
8. Ориентир: медиана `оценка формы / текущая цена` сопоставимых игроков.
9. Расчётная цена: `max(1, оценка формы / ориентир)`.
10. Отклонение сглаживается коэффициентом `матчи / (матчи + 5) × (0,5 + 0,5 × стабильность)`.
11. Порог рекомендации: одновременно не меньше 1,5к и 20% текущей цены.
12. Медиана текущего тура должна подтверждать направление минимум на 10% относительно ориентира.
13. Рекомендация: только один шаг ±1к, минимум 1к.

Полевым нужны 3 матча текущего тура, 5 всего и 3 подходящих игрока для сравнения.
Вратарям нужны 2 матча текущего тура, 8 всего и 1 подходящий вратарь.
Если загружено менее 80% матчей команды, начавшихся более 4 часов назад,
её рекомендации блокируются. Пустой протокол без ФО не считается загруженным.

Ценовые уровни команд сохраняются через отдельные группы сравнения, а не через
дополнительные коэффициенты лиг. Это относительная подсказка, не рыночная оценка:
травмы, игровую роль, корректность протоколов и баланс бюджета проверяет админ.
После ручного изменения цены повторный расчёт может предложить ещё один шаг;
лимита изменений за тур нет. Результаты не кешируются, страницы пересчитываются.

Проверка: `npm run test:prices` (также входит в `npm run check`).
Новых переменных окружения, зависимостей и миграций БД нет.
