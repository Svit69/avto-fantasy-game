# Помощник стоимости игроков

В админ-боте: `/admin` → «Помощник стоимости».
Расчёт ничего не записывает в цены и не меняет составы пользователей.
Кнопки «Изменить цену» открывают существующий ручной ввод стоимости.

## Данные

- Последний начавшийся регулярный тур и два предыдущих, определяемые по датам.
- Только завершённые импортированные матчи из календаря, без будущих матчей.
- Последний импорт каждого матча; старые строки игроков не восстанавливаются.
- Все фактически сыгранные матчи игрока, включая переходы между лигами.
- ФО уже содержат коэффициент лиги. Повторного умножения нет.
- Отсутствие строки игрока не равно нулю; настоящий ноль учитывается.
- Игроки, покинувшие игру, исключены.

## Форма и последние игры

1. Для каждого тура считаются среднее, медиана и количество матчей.
2. Веса текущего и предыдущих туров: 0,6 / 0,3 / 0,1.
3. Вес тура умножается на `min(матчи / 5, 1)`, доступные веса нормализуются.
4. Для оценки формы результаты ограничиваются медианой всей истории ± `max(15, abs(медиана))`.
5. База формы: взвешенные `0,7 × ограниченное среднее + 0,3 × ограниченная медиана`. Реальные ФО в отчёте не меняются.
6. Последние 1–2 игры текущего тура сортируются по дате, сравниваются с медианой остальных матчей.
7. Сильная игра: ФО выше этой медианы минимум на `max(10, abs(медиана) × 0,5)`.
8. Поправка: превышение среднего последних игр над базой, максимум `max(15, abs(база) × 0,75)`, с весом 15% для одного всплеска и 50% для двух.
9. Разброс: стандартное отклонение / `max(abs(среднее), 10)` по реальным ФО; стабильность: `1 / (1 + разброс)`.
10. Стабильный текущий тур: минимум 3 игры, не менее 80% положительных матчей, разброс не выше 0,35.

Полевым нужны 1 матч текущего тура, 5 всего и 3 подходящих игрока для сравнения.
Вратарям нужны 1 матч текущего тура, 8 всего и 1 подходящий вратарь.
Если загружено менее 80% матчей команды, начавшихся более 4 часов назад,
её рекомендации блокируются. Пустой протокол без ФО не считается загруженным.

## Бюджет и рекомендации

Бюджет и лимит клуба берутся из `FantasyRosterRules`: сейчас 90к и 4 игрока. Состав: 3 НАП + 2 ЗАЩ + 1 ВРТ.
Цена по группе = форма / медиана отдачи ФО на 1к других игроков текущей команды и позиции.
Бюджетный ориентир = бюджет × форма игрока / суммарная форма сильнейшего допустимого состава среди игроков с достаточными данными и полным покрытием команды.
Расчётная цена = `max(1, 60% цены по группе + 40% бюджетного ориентира)`; если полный опорный состав не собрать, используется только цена по группе.
Отклонение сглаживается коэффициентом `матчи / (матчи + 5) × (0,5 + 0,5 × стабильность)`.
Порог рекомендации: одновременно 1,5к и 20% цены; шаг ±1к, минимум 1к.
Рост подтверждается текущей медианой минимум на 10% выше группы либо двумя сильными играми; снижение — медианой на 10% ниже либо расчётной ценой ниже 75% текущей.
Все предложения проверяются вместе: повышение блокируется, если с игроком не собрать состав в бюджет. Снижения допускаются даже при уже недоступном рынке.
Точный подбор учитывает позиции, уникальность игроков и лимит клуба; в отчёте показываются минимальные стоимости до и после.
Это подсказка: травмы, роль, корректность протоколов проверяет админ. Повторный расчёт может предложить ещё один шаг; лимита изменений за тур нет.
Проверка: `npm run test:prices` (входит в `npm run check`). Новых зависимостей и миграций нет.
