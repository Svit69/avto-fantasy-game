# Онлайн-сбор КХЛ

Источник: https://avto-box.vercel.app/mirror.html?id=902107#stats

Воркер использует POST /api/capture и читает JSON, сохранённый зеркалом
из /rest/game/text/. Браузер на VPS не требуется. Снимок создаётся до
пяти минут; незавершённый, устаревший или ошибочный снимок не импортируется.
Медиа из потока не сохраняются. Ответ ограничен 32 МиБ.

## Запуск на VPS

```sh
git pull
npm ci
npm run check
pm2 restart avto-fantasy --update-env
pm2 start ecosystem.config.cjs --only avto-khl-online-poll
pm2 save
```

Не запускайте весь ecosystem повторно: существующий процесс ВХЛ может
называться avto-vhl-online-poll, а не как в конфигурации.

## Правила

- Матчи и khlGameId берутся из календаря, подготовка начинается за 10 минут.
- Пауза между запросами: минимум 5 минут после завершения предыдущего.
- После первого обнаруженного завершения: повторный сбор через 20 минут.
- После успешного финального сбора опрос этого матча прекращается.
- Ошибки повторяются в пределах 48 часов от календарного начала матча.
- При трёх ошибках подряд приходит одно предупреждение на матч.
- Админ получает подготовку, начало, один промежуточный и финальный результат.
- PDF и прежние ручные импорты важнее онлайн во всех представлениях.
- Игроки сопоставляются по ID либо уникальному имени во всей базе.
- Сейвы восстанавливаются по событиям с учётом замен и пустых ворот.
- При неполной статистике импорт отклоняется, прежние данные сохраняются.

Настройки .env: KHL_ONLINE_POLL_INTERVAL_MS=300000,
KHL_ONLINE_FINAL_DELAY_MS=1200000. Состояние: storage/runtime/khl-online-matches.json.
Heartbeat: storage/runtime/khl-heartbeat.json; /api/operations содержит khlWorker.
Сохраняйте runtime при развёртываниях: он содержит отметки завершения и уведомлений.
